這一章跟你的關係：第 1 章說「人 → 動作」是地基。這一章把地基後面可以接什麼，整理成五種形狀。你寫的每一句英文都是其中一種，認得形狀，就知道後面還缺什麼。
2-0

五種形狀，一張圖

動詞後面接什麼，決定句子的形狀。

S 是人（主詞），V 是動作（動詞）。V 之後有五種可能：什麼都不接、接一個「說明人的字」、接一個「被動作打到的東西」、接「給誰＋什麼」、接「東西＋東西變成什麼樣」。

C（補語）= 說明「是什麼樣」的字，用「=」想。O（受詞）= 被動作打到的東西，用「→」想。
POINT
  • 五種形狀都從「S + V」長出來，差別只在 V 後面接什麼。
  • 「=」是補語，「→」是受詞。分得清這兩個符號，五句型就會了。
2-1

句型 ①　S + V：動作停在自己身上

兩個字就是一句完整的話。

第 1 章說過：有些動作的力量停在自己身上（到達、發生、工作）。這種動詞後面不需要任何東西句子就完整。要補時間、地點，用介係詞片語掛在後面。

本體

The line stopped.

掛上去的

The line stopped at 3 p.m.

你工作上常用的 S + V注意
The samples arrived.
The problem happened again.
The machine works.
Prices went up.
It depends.		 arrive 後面不能直接接地點：arrive at the factory。
happen 不用被動。
depend 接東西要加 on：It depends on the quantity.
POINT
  • S + V 本身就完整；時間、地點是「掛件」，用介係詞掛上去。
  • arrive at / depend on / go up：這類動詞接東西一定先放介係詞。
2-2

句型 ②　S + V + C：用「=」說明主詞

be 動詞是一個等號。

He is busy = He「=」busy。等號右邊的字叫補語 C，它說明主詞是什麼、是什麼樣。除了 be，還有一群動詞也是等號：看起來、聽起來、變成、保持。

The customer is happy.

The schedule looks tight. ← 看起來很趕

The price became a problem.

Please stay calm. The line remains stable.

你最常犯的：等號右邊放錯字

等號右邊是「形容詞」或「名詞」，不是副詞。中文「看起來很好」的「好」是形容詞，英文一樣。

The result looks well.

The result looks good.

I feel badly about the delay.

I feel bad about the delay.

POINT
  • be、seem、look、sound、become、get、stay、remain 都是等號。
  • 等號右邊放形容詞或名詞，不放副詞：looks good，不是 looks well。
2-3

句型 ③　S + V + O：力量打在東西上

你寫的英文八成是這一型。

動作的力量射出去，一定要打到一個東西，那個東西叫受詞 O。第 1 章的「做了什麼？」就是在問 O。

受詞可以是一個字，也可以是一整件事

受詞的樣子例子
一個名詞We need the drawing.
一個代名詞We need it.
一個動作（to V 或 V-ing）We need to confirm the quantity.
They finished testing.
一整句話（that …）We confirmed that the samples passed.

「一個動作當受詞」第 3 章講，「一整句當受詞」第 6 章講。這裡先認得形狀。

中文不說受詞，英文一定要說

We will discuss 　 tomorrow. ← 討論什麼？

We will discuss it tomorrow.

Did you receive 　?

Did you receive the quotation? / Did you receive it?

POINT
  • S + V + O 是最常用的形狀，動作後面一定要有「被打到的東西」。
  • 中文省略的受詞，英文至少補一個 it。
2-4

句型 ④　S + V + 人 + 物：交東西給人

先寫給誰，再寫給什麼。

send、give、show、tell、offer 這類「交東西」的動詞，後面可以接兩個受詞：先人後物。中文「寄給你報價」，英文是 send you the quotation——人直接貼在動詞後面，不用 to。

形狀 A：人先，不用 to

I'll send you the quotation.

形狀 B：物先，人用 to

I'll send the quotation to you.

兩種都對。物很長的時候用 B，不然人會被夾在中間聽不清楚。

I'll send you the file.

I'll send the updated drawings for the new connector to you.

to 類（把東西「遞」過去）for 類（「為對方」做）
send / give / show / tell / offer / lend
→ send it to him		make / get / buy / find
→ make a sample for him

to 跟 for 的差別第 1 章講過：to 是東西真的移到對方手上，for 是為了對方。

這一型特別常錯的

Please explain me the process. ← explain 不走句型 ④

Please explain the process to me.

explain、suggest、describe、introduce 不能把人直接貼在後面，一定走「物 + to 人」。

POINT
  • send / give / show / tell：人先物後不用 to；物先人後要用 to。
  • 物很長 → 物先，to 人放最後。
  • explain / suggest / describe 永遠是「物 + to 人」。
2-5

句型 ⑤　S + V + O + C：東西變成什麼樣

先打到東西，再說它變成什麼。

句型 ③ 的受詞後面，再加一個「=」說明受詞的狀態，就是句型 ⑤。O = C：我們把它（O）弄成完成（C）。

We keep the line running. 我們讓產線保持運轉。
動詞例句（O = C）
keep 保持Keep the samples = dry.
Please keep me = posted. 隨時通知我
make 使…變成The delay made the customer = unhappy.
This makes the process = easier.
find 發現…是We found the connector = damaged.
call / nameWe call this part = the housing.
get / have 把…弄成We got it = done.　I'll have the report = ready by Friday.
consider 認為We consider the test = a success.

③ 還是 ⑤？問一句「O 等不等於後面那個字」

I sent him the file.

him = the file？不等於 → 句型 ④（人＋物）

I found the file corrupted.

the file = corrupted？等於 → 句型 ⑤（O = C）

POINT
  • 句型 ⑤ = 受詞 + 等號：keep it dry、make it easier、get it done。
  • Keep me posted / Keep me updated 是職場天天用的句型 ⑤。
  • 分 ④ 和 ⑤：後面兩個字能不能畫等號。
