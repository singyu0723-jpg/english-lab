2+-1

可數／不可數：數得出「一個一個」嗎

能一個一個數的，才有 a 和 s。

英文把名詞分成兩種：有邊界的東西（一個連接器、兩條線）和沒有邊界的東西（資訊、設備、水）。沒有邊界的，不能說「一個」，也不能加 s。

information 資訊equipment 設備advice 建議feedback 回饋progress 進度work 工作packaging 包裝training 訓練 a piece of information / some informationa piece of equipment / three machinessome advice / a suggestionsome feedback / a commenta lot of progressa job / a taska package / a boxa training session

We need more informations.

We need more information.

The customer gave us some advices.

The customer gave us some advice. / gave us a few suggestions.

同一個字，有時可數有時不可數

看你畫的是「一個個」還是「一團」。

We produce cable.（材料，一整團）

We shipped 200 cables.（一條一條，成品）

We have experience in this.（累積的經驗）

It was a bad experience.（一次事件）

It takes time.（時間本身）

We did it three times.（次數）

POINT
  • information / equipment / advice / feedback / progress 永遠不加 s，也不接 a。
  • 要數就借單位：a piece of、some、a lot of。
  • cable、experience、time：一個個 → 可數；一團 → 不可數。
2+-2

a / an / the / 不加：對方知不知道你指哪一個

the = 你和對方都知道是哪一個。

冠詞不是文法規則，是在告訴聽的人要不要去找「那一個」。a 是「隨便一個／第一次提到」，the 是「就是那一個，你知道的」，不加是「泛指這類東西」。

一封 email 裡的 a → the

We received a complaint from the customer.（第一次提：一件客訴）

The complaint is about the connector pitch.（第二次提：就是那件）

第一次出場用 a，之後都用 the。這是最常用也最簡單的規則。

什麼時候一定是 the

情況例子
只有一個、對方一定知道的the customer（這個案子的客戶）the factorythe manager
後面有說明是「哪一個」the drawing you sent yesterdaythe result of the test
最高級、序數the best optionthe first batchthe same spec

什麼時候不加

We need samples by Friday.（泛指，複數）

We need approval first.（不可數）

I go to work at eight.

He is in charge.

at noon

on time（固定片語不加）

a 還是 an：聽聲音

a sample

a unit（u 唸 ju，子音）

a one-year warranty（one 唸 w）

an order

an hour（h 不發音）

an MOQ（M 唸 em，母音開頭）

POINT
  • 第一次提 a，再提 the；對方一定知道哪一個 → the。
  • 泛指複數、不可數 → 不加。
  • a / an 看發音不看字母：an hour、a unit、an MOQ。

代名詞：人稱與所有格

同一個「我」，在句子的不同位置長得不一樣。

中文「我」永遠是「我」；英文站在動詞前面是 I，被動作打到是 me，擁有東西是 my，「我的那個」是 mine。

I sent him my report. The other one is mine.

三個常錯

Please send the file to I.

→ to me

介係詞後面是「被打到」的形式

The customer and me discussed it.

→ The customer and I

做動作的用 I

It's pitch is 0.5 mm.

→ Its pitch is 0.5 mm.

it's = it is；its 才是「它的」

it / they 指誰：先找前面的名詞

We tested the samples. They passed.（複數 → they）

We tested the sample. It passed.（單數 → it）

The customer called. They want a discount.（公司當一群人 → they 也常見）

POINT
  • 動詞前面 I / he / they；動詞或介係詞後面 me / him / them。
  • my 後面接名詞，mine 後面不接。
  • its 是「它的」，it's 是 it is。

反身、指示、不定代名詞

-self：動作打回自己身上，或強調「親自」

打回自己

I'll check it myself.

我親自確認（強調）

by + self = 一個人、沒人幫

He set up the machine by himself.

The system restarts by itself.

自動重啟

this / that / these / those：遠近 + 單複數

近（手邊、剛講的）遠（那邊、之前講的）
單數this sampleThis is the new version.that sampleThat was last year's spec.
複數these samplesthose samples

Email 裡：This is to confirm our meeting on Friday.（指「這封信」的事）

That works for me.（指對方剛說的提議）

one / ones：換掉重複的名詞

We don't need the old sample; we need the new sample.

We don't need the old sample; we need the new one.

These connectors are fine, but those ones are damaged.

some / any / every- / no-

字怎麼用
some / any肯定句 some、疑問否定 any：We have some stock. Do you have any questions? We don't have any left.
something / anything / nothingIs there anything else? There's nothing wrong with it.
everyone / everything後面動詞用單數：Everyone is here. Everything is ready.
each / everyEach sample was tested.（一個一個）Every batch is checked.
POINT
  • myself = 親自；by itself = 自動、沒人幫。
  • this 近 that 遠；That works for me 是回覆提議的萬用句。
  • one / ones 代替重複的名詞；everyone / everything 接單數動詞。
