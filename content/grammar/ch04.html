這一章跟你的關係：你的句子時態大多對，錯的集中在三個地方：該用現在完成式的地方用了過去式（已經寄了 ≠ 昨天寄的）、第三人稱單數忘了加 s、不規則動詞記錯。這一章用時間軸把 12 個時態畫成一張圖，再把你會用到的 6 個練熟。其他 6 個看得懂就好。
4-1

12 種時態，一張圖

3 個時間 × 4 種樣子。

時間只有三個：過去、現在、未來。每個時間的動作有四種「樣子」：一個點（簡單式）、正在進行（進行式）、到這之前完成了（完成式）、一直做到這（完成進行式）。3 × 4 = 12，不用背，看圖。

點 = 簡單式、波浪 = 進行式、箭頭到一條線 = 完成式。藍色那一欄是「現在」。

你真正會用到的 6 個

職場 email 和口說，九成句子落在這 6 格：現在簡單、現在進行、過去簡單、未來（will / be going to）、現在完成、現在完成進行。4-2 到 4-4 只練這 6 個；4-5 把剩下的看懂。

POINT
  • 時態 = 時間（過去／現在／未來）× 樣子（點／波浪／箭頭到線／波浪到線）。
  • 先練 6 個常用的，其他 6 個看得懂就好。
4-2

現在簡單 vs 現在進行

簡單式是「一向如此」，進行式是「此刻、暫時」。

現在簡單：事實、習慣、固定流程

We ship every Friday.

The line runs 24 hours.

This connector supports 10 A.

現在進行：現在正在、這陣子

We are testing the new batch.

I'm working on the quotation.

Prices are going up this quarter.

第三人稱單數要加 s（主詞動詞一致）

現在簡單式裡，主詞是 he / she / it / 一個東西 / 一家公司，動詞加 s。這是你最常漏的一個字母。

主詞是「一個」主詞是「多個」或 I / you
The customer wants a discount.Our supplier has the parts.The machine doesn't work.Everyone is here.Each sample passes.The customers want a discount.Our suppliers have the parts.The machines don't work.I / You / We / They want…

主詞很長時找「頭」：The price of these connectors is too high.（price 是頭，單數）

有些動詞不用進行式

I'm knowing the answer. / We're having two options.

I know the answer.

We have two options.

I think so.

It depends.

know、have（擁有）、need、want、believe、understand：狀態不是動作，不會「正在」。但 have 當「吃／開會」可以：We're having a meeting.

POINT
  • 一向如此 → 簡單式；此刻、這陣子 → 進行式。
  • he / she / it / 一家公司 / everyone / each → 動詞加 s。主詞長的找頭。
  • know / have / need / want / understand 不用進行式。
4-3

過去簡單 vs 未來

過去簡單：講明是「那時候」

We shipped the samples yesterday.

The customer called this morning.

I sent it last Friday.

未來：will / be going to / 進行式

I'll send it tomorrow.

We're going to change the material.

The customer is visiting next Tuesday.

三種未來的差別

說法感覺例句
will當場決定、承諾、預測OK, I'll check and get back to you.It will take about two weeks.
be going to早就打算、看得出跡象We're going to switch suppliers next year.Look at the data — it's going to fail.
現在進行式已經安排好的行程The customer is visiting on Tuesday.I'm flying to Vietnam next week.

過去式的三個小坑

Did you sent it? → Did you send it?

did 已經帶過去，動詞回原形

I didn't received it. → I didn't receive it.

We have shipped it yesterday. → We shipped it yesterday.

有明確過去時間就不用完成式（4-4 細講）

POINT
  • yesterday / last week / in 2024 / ago → 過去簡單，不要用完成式。
  • will 當場決定；be going to 早有打算；進行式 = 排好的行程。
  • did / didn't 後面動詞回原形。
4-4

現在完成：從過去拉一條線到現在

have + V-ed = 這件事到「現在」為止的狀態。

過去式是「那時候發生的一個點」，跟現在沒關係。現在完成式是過去的事拉到現在：已經做了（所以現在可以下一步）、做過（所以現在有經驗）、做了多久（到現在還在）。

I sent it.（昨天的事）　I've sent it.（已經寄了，你現在可以去收）

三種用法，三組關鍵字

意思關鍵字例句
已經／還沒
結果影響現在		already, just, yet, not … yetI've already sent the quotation.We've just received the PO.They haven't replied yet.
做過／沒做過
到現在為止的經驗		ever, never, beforeHave you ever worked with this supplier?We've never had this problem before.
做了多久
從過去持續到現在		for + 一段, since + 起點I've worked here for five years.We've used this material since 2022.

什麼時候用哪個：有沒有講「那時候」

I sent it yesterday.

We fixed it last week.

有明確過去時間 → 過去式

I've sent it.（已經寄了）

We've fixed it.（已經修好）

沒講時間、重點是「現在怎樣」 → 現在完成

現在完成進行：強調「一直在做」

We've been working on this issue for two days.（一直在處理，還沒完）

I've been waiting for the report since Monday.

have been V-ing：線上有波浪。重點是「過程持續」，常配 for / since。

POINT
  • 有「那時候」→ 過去式；沒時間、講「現在狀態」→ 現在完成。
  • already / just / yet / ever / never / for / since 看到就是現在完成。
  • have been V-ing = 一直做到現在，還在做。
4-5

過去完成、未來完成：看得懂就好

完成式的「線」往左右移。

現在完成是「拉到現在」。把終點移到過去的某個時間，就是過去完成；移到未來的某個時間，就是未來完成。

時態什麼時候用例句
had + V-ed過去完成講過去兩件事，要說哪一件更早When the customer arrived, we had already finished the test.I had sent the file before he asked.
will have + V-ed未來完成到未來某個時間點會做完By Friday, we will have shipped all the samples.By the end of the year, I'll have worked here for six years.
was / were + V-ing過去進行過去某一刻正在做，常配另一件事插進來I was testing the sample when the power went out.
will be + V-ing未來進行未來某一刻正在做This time next week, I'll be flying to Vietnam.

過去完成進行（had been V-ing）、未來完成進行（will have been V-ing）極少用，看到認得就好。

POINT
  • 過去完成 = 過去兩件事裡「更早的那件」：had + V-ed。
  • 未來完成 = by + 未來時間 + will have + V-ed。
  • 口說少用這些；email 裡 by Friday we will have… 偶爾用得上。
4-6

動詞變化與不規則動詞

每個動詞三個樣子：原形、過去式、過去分詞。

規則動詞加 -ed 兩次。不規則動詞要記，但你工作上會用到的就這 40 個。分三型記比較快。

位置用例

POINT
  • 三型記：三個一樣（cut）、後兩個一樣（send-sent-sent）、三個不同（go-went-gone）。
  • have / be 後面一律第三個樣子（過去分詞）。
  • did / will / can 後面回原形。
