這一章跟你的關係：報價和談判全是「如果」：如果你們訂 1 萬條、如果銅價漲、如果早點收到 PO 就能早出貨。英文的「如果」分成真的可能和只是想像兩種，動詞長得不一樣。分對了，對方就知道你在認真報價還是在假設。
10-1

條件句 vs 假設語氣：真的可能，還是只是想像

動詞往後退一格 = 我在想像，不是在講事實。

真的可能（條件句）：if + 現在式，主句 will / can / 命令

If the test passes, we will ship on Friday.

If you need it earlier, let me know.

If copper goes up, the price may change.

注意：if 後面講未來也用現在式，不寫 if the test will pass。

when / unless / as long as 用法一樣

When we receive the PO, we'll start production.（確定會收到）

Unless we get the drawing today, we can't start.（= if we don't）

As long as the spec doesn't change, the price stays the same.（只要）

POINT
  • 真的可能：if + 現在式，主句 will。if 後面不放 will。
  • 動詞退一格（過去式 + would）= 只是想像，不會真的發生。
  • unless = if not；as long as = 只要。
10-2

假設語氣過去式：對現在／未來的想像

if + 過去式，主句 would / could + 原形。

講的是「現在不是這樣」或「不太可能」。時態往後退一格，是在跟對方說：我知道這不是真的。

if + 過去式主句 would / could
If the price were lower,we would order more.（現在價格不低）
If we had a second line,we could ship faster.（現在沒有）
If I were you,I would accept the offer.（我不是你）

be 動詞在假設句一律用 were（If I were / If it were）；口語 was 也常見，書面用 were。

談判用法：把條件講軟

If you could increase the quantity, we could offer a better price.

比 If you increase…, we will… 客氣，留餘地。

What would happen if we changed the material?

探詢，不承諾。

POINT
  • if + 過去式, would + 原形 = 現在不是這樣／不太可能。
  • If I were you, I would… 是給建議的固定句。
  • 談判用 could…could 把條件講軟。
10-3

假設語氣過去完成式／混合：對過去的「早知道」

if + had + V-ed，主句 would have + V-ed。

事情已經過去，結果已定，回頭假設。檢討報告的句型。

if + had + V-edwould have + V-ed
If the PO had come earlier,we would have shipped last week.
If we had tested the first batch,we would have caught the defect.
If I had known,I would have told you.

混合型：過去的假設，影響到現在

If we had ordered more copper last month, we wouldn't be short now.

if 用過去完成（上個月），主句用 would + 原形（現在）。

wish：希望現實不是這樣

I wish we had more time.（現在沒有 → 過去式）

I wish we had tested it earlier.（過去沒測 → 過去完成）

I wish the customer would reply faster.（希望對方改變）

POINT
  • 對過去：if + had V-ed, would have V-ed。
  • 混合：過去的 if + 現在的結果（would + 原形）。
  • wish + 過去式 = 現在不是；wish + had V-ed = 過去沒有。
10-4

倒裝：把 if 拿掉

正式 email 把 if 省掉，助動詞搬到前面。

有 if省 if（倒裝）
If you have any questions,Should you have any questions, please contact me.
If we were to change the material,Were we to change the material, the cost would rise.
If we had known earlier,Had we known earlier, we would have ordered more.

只有 Should you… 是你自己要會寫的，其他看得懂就好。

10-5

其他假設句型

句型例句
in case（以防萬一）Please keep a backup in case the file gets corrupted.
otherwise（否則）We need the PO by Friday; otherwise, the schedule will slip.
without（沒有…的話）Without your approval, we can't start.
as if（好像）He talks as if he were the customer.
suggest / recommend that + 原形We suggest that the customer use a thicker jacket.I recommend that he be informed.（建議句裡的動詞用原形，美式）
It's time + 過去式It's time we replaced that machine.
POINT
  • in case = 以防；otherwise = 否則；without = 沒有的話。
  • suggest / recommend that + 原形（that he be…）。
