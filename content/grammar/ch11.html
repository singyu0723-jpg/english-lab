這一章跟你的關係：「上次會議提到的問題」「昨天寄的圖面」「負責這個案子的工程師」——中文把說明放名詞前面，英文放後面，用 who / which / that 接上去。你第 1 章就寫過 the issue we discussed，其實已經在用了。這一章把它系統化。
11-1

關係代名詞：名詞後面掛一句說明

先講名詞，再用 who / which / that 把說明掛上去。

掛鉤前面的名詞是例句
who人the engineer who handles this casethe customer who called yesterday
which東西the drawing which you sent yesterdaythe machine which broke down
that人或東西都可以（口語最常用）the issue that we discussedthe supplier that makes the housing
whose…的（所有格）the customer whose order was delayed

掛鉤在說明句裡當主詞還是受詞？受詞可以省

the engineer who handles this case（who 是 handles 的主詞 → 不能省）

the drawing (which) you sent yesterday（which 是 sent 的受詞 → 可以省）

the issue (that) we discussed → the issue we discussed ✓

判斷法：掛鉤後面如果馬上接「人 + 動詞」（you sent、we discussed），掛鉤是受詞，可以省。

你最常犯的：掛鉤後面又放一次代名詞

the issue that we discussed it last week

the issue that we discussed last week

that 已經代表 the issue 了，後面不要再放 it。

POINT
  • 人 who、東西 which、都可以 that、所有格 whose。
  • 掛鉤是受詞（後面接「人 + 動詞」）可以省。
  • 掛鉤後面不要再放 it / them。
11-2

that 與 what

一定用 that 的時候

all / everything / nothing / the only / 最高級 後面 → that

This is everything that we have.

It's the only supplier that can do 28 AWG.

the best price that we can offer

what = the thing(s) that：前面沒有名詞

that：前面有名詞

the spec that the customer wants

掛在 the spec 後面

what：自己就是名詞

what the customer wants

= the thing that the customer wants

Please tell me what you need.

What we need is a firm PO.

This is what I meant.

Please tell me the spec what you need. → the spec that you need

POINT
  • everything / the only / 最高級 後面用 that。
  • what 前面不放名詞；what = the thing that。
11-3

要注意的句子：逗點、介係詞

有逗點 = 補充說明（整個都在講），沒逗點 = 限定是哪一個

沒逗點：限定

The samples that failed were from batch 3.

只有「失敗的那些」樣品來自第 3 批（還有其他沒失敗的）

有逗點：補充

The samples, which failed, were from batch 3.

樣品（順便說，它們失敗了）來自第 3 批（全部都失敗）

有逗點時只能用 who / which，不能用 that。

which 指前面整件事

The supplier missed the date again, which is unacceptable.

They approved the drawing, which means we can start.

介係詞跑到哪裡

the supplier (that) we work with（口語：介係詞留在後面）

the supplier with whom we work（正式：介係詞搬到前面，who → whom）

the project (that) I'm responsible for / the project for which I'm responsible

口說一律留在後面就好。

POINT
  • 沒逗點 = 限定哪一個；有逗點 = 補充，只能 who / which。
  • , which = 前面整件事。
  • 介係詞留在句尾：the supplier we work with。
11-4

關係副詞：where / when / why

掛的不是「東西」，是地點、時間、原因。

掛鉤前面的名詞例句
where地點the factory where we make the cablethe folder where I saved the file
when時間the day when the samples arrivedthe week when prices went up
why原因（the reason）the reason why the test failed

where / when / why 後面是完整的句子（有主詞有受詞）；which / that 後面少一個東西。

the factory where we make the cable（we make the cable 完整）

the factory that we visited（we visited ___ 少受詞）

POINT
  • 地點 where、時間 when、原因 why；後面接完整句。
  • which / that 後面的句子少一個東西（掛鉤就是那個東西）。
11-5

複合關係代名詞：whoever / whatever / whichever

Whoever approved this should sign here.（任何核准的人 = anyone who）

Send me whatever you have.（任何你有的 = anything that）

Choose whichever is cheaper.（哪一個都行）

Whenever you're ready, let me know.（任何時候）

Wherever the parts are, we need them today.

-ever = 任何。口說常用 whatever / whenever，其他看得懂就好。

POINT
  • whoever = anyone who；whatever = anything that；whenever = any time。
