這一章跟你的關係：你的句子常常是「一句、一句、一句」各自獨立，或者用 and 串到底。連接詞決定兩句話的關係：因為、雖然、所以、只要。用對了，一段英文就有邏輯；用錯了，對方要猜。
12-1

連接詞的種類：平等的、從屬的

兩句話，是平起平坐，還是一句掛在另一句下面？

POINT
  • 對等連接詞（and / but / or / so）：兩句平等。
  • 從屬連接詞（because / although / if / when…）：帶的那句是附屬，不能單獨成句。
12-2

對等連接詞與配對連接詞

字關係例句
and而且、然後We tested the sample and sent the report.
but但是The price is good, but the lead time is too long.
or或者We can ship by air or by sea.
so所以（結果）The PO was late, so the schedule slipped.
yet但是（正式）The spec is simple, yet the tolerance is tight.

兩句完整句子用 and / but / so 連，中間加逗點。

配對連接詞：兩個字一組

組例句
both A and BWe need both the drawing and the spec.
either A or BYou can pay either by T/T or by L/C.
neither A nor BNeither the price nor the lead time is acceptable.
not only A but also BThe new line is not only faster but also cheaper to run.

A 和 B 要是同樣的東西：名詞配名詞、動詞配動詞。both fast and to be cheap → both fast and cheap

POINT
  • and 而且、but 但是、or 或、so 所以。
  • both…and、either…or、neither…nor、not only…but also：兩邊形狀要一樣。
12-3

從屬連接詞：時間、原因、讓步、條件

類型字例句
時間when / while / before / afterWhen we receive the PO, we'll start.
Before you ship, please double-check the label.
until / as soon as / onceWe'll wait until the test is done.
As soon as it arrives, I'll let you know.　Once approved, it can't be changed.
原因because / since / asWe stopped because we found a defect.
Since the price went up, we need to re-quote.
讓步
雖然		although / though / even thoughAlthough the sample passed, the customer wants another test.
Even though it's expensive, it's worth it.
條件if / unless / as long as / in case（第 10 章）Unless we hear from you, we'll proceed.
目的／結果so that / so … thatWe added a label so that the operator can see the lot number.
The delay was so long that the customer cancelled.

從屬句可以放前面或後面

Because the PO was late, we couldn't start.（放前面要逗點）
We couldn't start because the PO was late.（放後面不用逗點）

你最常犯的兩個

Although the price is high, but the quality is good.（中文「雖然…但是」，英文只能留一個）

Although the price is high, the quality is good. / The price is high, but the quality is good.

Because the PO was late, so we couldn't start.

Because the PO was late, we couldn't start. / The PO was late, so we couldn't start.

POINT
  • although 和 but 只能選一個；because 和 so 只能選一個。
  • 從屬句放前面加逗點，放後面不加。
  • as soon as、once、so that 是 email 裡最好用的三個。
12-4

連接詞 vs 介係詞 vs 副詞：後面接什麼

同一個意思，三種字，後面接的東西不同。

意思連接詞（接一句話）介係詞（接名詞）副詞（自己一句，前面句點或分號）
因為because the PO was latebecause of the late PO
due to the delay		—
雖然although it is expensivedespite the cost
in spite of the cost		It's expensive. However, it's worth it.
所以…, so we stopped—…. Therefore, we stopped.
…. As a result, …
期間while we were testingduring the testMeanwhile, …
此外—besides the cost
in addition to the cost		Besides, … / In addition, … / Also, …

The shipment was delayed because the typhoon. → because of the typhoon　後面是名詞

Despite it is expensive, … → Although it is expensive, …　後面是句子

The PO was late, therefore we stopped. → The PO was late. Therefore, we stopped. / The PO was late; therefore, …

email 裡怎麼接段落

However, …（轉折）　Therefore, …（結論）　In addition, …（補充）　For example, …（舉例）　Otherwise, …（否則）　Meanwhile, …（同時）

這些副詞開頭，後面加逗點，前面是句點。不要用它們直接連兩句。

POINT
  • 接句子 → because / although / while；接名詞 → because of / despite / during。
  • However / Therefore / In addition 是副詞：前面句點，後面逗點。
