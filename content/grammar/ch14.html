這一章跟你的關係：你問過 allocate / calibration 是什麼詞性。多益 Part 5 有一半在考這個：空格要填名詞、動詞、形容詞還是副詞。這一章不是新文法，是把前面 13 章用到的「零件」分類標好，讓你看到一個字就知道它能放哪裡。
14-1

八大詞類：句子的零件

每個字都有一個「可以放的位置」。

同一個字根，四種形狀

名詞動詞形容詞副詞
production / productproduceproductiveproductively
reliabilityrelyreliablereliably
approvalapproveapproved—
calibrationcalibratecalibrated—
allocationallocateallocated—
significancesignifysignificantsignificantly

字尾就是詞性的招牌：-tion / -ment / -ness / -ity 是名詞，-able / -ive / -al / -ous 是形容詞，-ly 幾乎都是副詞，-ate / -ize / -ify 是動詞。

POINT
  • 看字尾認詞性：-tion 名、-able 形、-ly 副、-ate 動。
  • 一個字根通常有四種形狀，背單字時四個一起看（單字卡的「衍生字家族」就是這個）。
14-2

片語與子句：一群字當一個零件

片語 = 沒有「主詞 + 動詞」的一群字；子句 = 有「主詞 + 動詞」的一群字。

子句的三種身分例句哪一章
名詞子句（當名詞）I think that we can make it.I don't know if he's coming.第 6 章
形容詞子句（修飾名詞）the drawing that you sentthe engineer who handles it第 11 章
副詞子句（修飾整句）Because the PO was late, we stopped.If it passes, we ship.第 10、12 章
POINT
  • 片語沒有主詞動詞；子句有。
  • 子句三種身分：當名詞（that / if）、修飾名詞（who / which）、修飾整句（because / if / when）。
14-3

句子成分：S / V / O / C / M

第 2 章的五大句型 + 一個 M（修飾語）。

把一句長英文拆開：先找動詞 V，動詞前面是主詞 S，後面是受詞 O 或補語 C，剩下的時間、地點、方式都是 M（修飾語，可以拿掉）。

拆長句的步驟

The revised quotation that we sent last week is still valid until the end of the month.

① 找當家動詞：is（that 子句裡的 sent 不算，它在括號裡）
② 動詞前面整坨是主詞：The revised quotation that we sent last week
③ is 後面是補語：valid
④ 剩下 until… 是 M。
骨架：The quotation is valid. 其他都是裝飾。

多益 Part 5 的解法

空格前後看位置：冠詞和介係詞之間 → 名詞；名詞前面 → 形容詞；動詞前後、句首逗點前 → 副詞；主詞後面缺動詞 → 動詞。

The ______ of the new line took two weeks.（the ___ of → 名詞 → installation）

Please handle the samples ______.（動詞後面 → 副詞 → carefully）

We need a more ______ supplier.（名詞前 → 形容詞 → reliable）

POINT
  • 拆句：先找當家動詞，前面是 S，後面是 O 或 C，其他是 M。
  • 讀長句先抓骨架 S + V + O，再看裝飾。
  • 填空看位置：the ___ of 名詞、名詞前形容詞、動詞旁副詞。
